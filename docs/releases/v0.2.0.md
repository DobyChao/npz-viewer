# v0.2.0

桌面端连接管理迁到 Rust，Windows 便携包不再携带 Node 运行时。

- Tauri / Rust 管理 SSH、SFTP、隧道和独立标签页会话，页面内嵌到 exe。
- 本机 Python 在首次本机数据请求时启动；保留 NumPy、Pillow 和 FFmpeg，支持离线处理与视频导出。
- 远端连接继续先探测端口和健康状态，同用户已有健康后端则直接复用；支持中断连接。
- 保留 Node 浏览器入口与纯 Python 单进程模式。
- 前端、Tauri 和 Python 后端版本统一为 0.2.0。

Windows x64 下载 `npz-view-0.2.0-windows-x64.zip`，解压到普通文件夹后双击 `npz-view.exe`。无需另装 Node / Python；系统需要 WebView2。不要放到 Program Files。
